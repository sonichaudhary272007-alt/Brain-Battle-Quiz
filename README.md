# 🧠 Brain Battle – Interactive Quiz Application
An interactive and engaging quiz application built using **HTML, CSS, and JavaScript**, designed to help users test their knowledge across multiple categories and difficulty levels.
Brain Battle provides a dynamic quiz experience with instant answer feedback, real-time score tracking, and a responsive user interface.

## ✨ Features
- 📚 **Multiple Categories:** General Knowledge, Computer Science, Science, History, Sports, and Geography.
- 🎯 **Three Difficulty Levels:** Easy, Medium, and Hard.
- 🔢 **Flexible Quiz Length:** Choose 5, 10, 15, or 20 questions.
- 🌐 **Dynamic Questions:** Fetches quiz questions using the Open Trivia Database API.
- ⚡ **Instant Feedback:** Displays feedback after selecting an answer.
- 📊 **Real-Time Score Tracking:** Keeps track of the user's performance.
- 📈 **Progress Tracking:** Visual progress bar to monitor quiz completion.
- 🏆 **Results Screen:** Displays the final quiz score.
- 🔄 **Play Again:** Allows users to restart and challenge themselves.

## 🛠️ Technologies Used
| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling, animations, gradients, and responsive UI |
| JavaScript | Quiz logic, DOM manipulation, and event handling |
| Open Trivia Database API | Fetching dynamic quiz questions |

## 🔌 API Integration
Brain Battle uses the **Open Trivia Database API** to retrieve quiz questions dynamically.
API: https://opentdb.com/api_config.php
The application uses API responses to display questions, answer options, and correct answers based on the selected quiz settings.

## 💻 How to Run Locally
1. Clone this repository:
   git clone https://github.com/sonichaudhary272007-alt/Brain-Battle-Quiz.git
   

2. Open the project folder:
   cd Brain-Battle-Quiz

3. Open index.html in your browser.

4. Select your preferred category, difficulty level, and number of questions.

5. Start playing Brain Battle!
